🔑 Token du bot Discord

Le token identifie ton bot Discord. Ne le partage jamais.
Il sera sauvegardé dans le fichier .env du bot.

📋 Permissions Discord requises

Dans le portail développeur Discord, ton bot doit avoir :

BotView Channels — voir les canaux du serveur
BotRead Message History — lire les commandes !join
BotSend Messages — répondre aux commandes
BotConnect — rejoindre un canal vocal
BotSpeak — nécessaire pour recevoir l'audio
BotUse Voice Activity — détecter qui parle
Privileged IntentMessage Content Intent — lire le contenu des messages (!join)
Privileged IntentServer Members Intent — récupérer les displayNames

⚠ Privileged Intents

Les deux intents marqués doivent être activés manuellement dans Bot → Privileged Gateway Intents du portail développeur.
